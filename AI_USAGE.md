# AI usage

ETHGlobal asks teams to document where and how AI tools were used. This file is kept up to date as work happens.

## Tool

Claude Code, using Claude Opus 5.5.

## How the work is divided

Crossfare is a solo project. AI writes the code, tests and most documentation. The developer sets the direction and steps in manually to fix issues.

**The developer:**

- owns the product idea, and did the product research behind it
- designed the product: the FixedFloat-style flow, where anyone gets a deposit address without connecting a wallet; asking for the receiving address on cross-chain swaps; deposits from an exchange; a 30-minute quote instead of 72 hours; prices shown next to every quote
- set the scope and requirements, and makes the decisions, such as working solo, keeping Uniswap for same-chain swaps, making the swap call free for now, swapping an over-sized deposit in full rather than holding funds, and hosting on EC2 and Vercel
- sets the working rules in [`CLAUDE.md`](CLAUDE.md)
- tested each live build by hand and reported what was wrong. That found the order page dropping its deposit address before any deposit arrived (the developer suspected a race; AI traced it to SwapKit's placeholder hashes), the page staying on "Send your deposit" after a deposit landed, wrong wording on the refund address, and a UI that needed redoing
- creates accounts, keys and funded wallets, and approves and sends any real funds
- funded all five real swaps. AI ran the first, 2 USDC through the agent, from this machine on the developer's instruction. The developer sent the deposits for the other four from their own wallet app, three of them on the deployed site
- deployed the API to EC2 and the UI to Vercel
- supplied the logo and the video's cover image
- recorded and edited the demo video

**AI:**

- researched the event rules and the partner APIs
- redrew the developer's logo as an SVG for the UI
- wrote the application code and tests
- wrote commit messages and documentation
- drafted the requirements document from the developer's direction, and kept it updated as decisions changed

## How the AI was directed

[`docs/prompts.md`](docs/prompts.md) records the developer's prompts, and [`docs/prd.md`](docs/prd.md) is the requirements document that directed the work.

`docs/prd.md` is a copy of a private working document, with two things removed: the analysis of SwapKit's terms, and the plans for integrating with CoinDrop, the developer's own product. The file's opening note gives the details.
